# Chaos Dynamics and Error Propagation: Simulating the Lorenz Attractor

A numerical exploration into deterministic chaos using Python, evaluating the performance bounds of explicit integration algorithms and mathematically quantifying the Butterfly Effect via Lyapunov exponents.

### Modules needed:

* Numpy
* Matplotlib
* Scipy
